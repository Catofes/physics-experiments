# 电磁场实验来源与整合范围

2026-09-20 根据用户提供的两个实验页面，将数值模型与绘图迁入站内 Vue 模块：

- [磁场 AI 可视化实验室](https://jaccihan.github.io/magnetic-field-visualization-v2/)（[原仓库](https://github.com/jaccihan/magnetic-field-visualization-v2)）：沿用 `field-core.js`、`compute-job.js`、`compute-client.js` 中的模型、后台任务及取消机制，以及 `app.js` 中的场源几何、线条、箭头和热力图绘制。
- [静电场 AI 可视化实验室 · 腔内电荷](https://jaccihan.github.io/electrostatic-field-ai-demo/#cavity)（[原仓库](https://github.com/jaccihan/electrostatic-field-ai-demo)）：沿用 `app.js` 中的二维边界元计算、电场线、等势线、表面电荷与场景绘图。

来源作者为 GitHub 用户 **jaccihan**。上述说明记录来源，不声明对原代码的额外许可。本站目录封面为新绘制的 SVG 示意图。

## 站内模块

磁场地址为 `/experiments/magnetic-field`，包含地磁场、条形磁铁、弯折导线、通电直导线、双导线、环形电流、通电螺线管。保留场源参数、预测模式、截面投影、热力图、点选采样与双导线矢量合成。原站另链出的“教室磁场图”是独立页面，本次不纳入。学生／教师模式统一为教师控制的预测／揭示按钮，观察说明及诊断随预测模式一起隐藏。

静电场地址为 `/experiments/electrostatic-field`，默认腔内电荷，另可选择带电球体、空腔屏蔽、尖端效应、哑铃导体、避雷针、实心导体。保留电荷拖动、正负与大小、预测模式、场线、等势线及诊断。避雷针场景使用原模型中的正电势板与零电势导体，控件显示为相对电极电压。

Vue 管理控件、导航、暂停和重置；绘图模块只接收挂载节点、状态与回调。静电场内部拖动位置由该实例维护，场景切换恢复对应位置。退出后取消动画与事件；磁场额外终止计算线程、断开尺寸观察、释放材质、几何体、纹理和 WebGL 上下文。Three.js 与 Worker 随 Vite 本地打包，不使用原站的运行时资源、预计算缓存、iframe、全局调试入口或外部 AI 服务。

## 模型边界与验证

磁场沿用参考模型的单位换算、导线近场屏蔽和理想化场源；解析关系自检覆盖 45 个检查项。热力图按当前截面 P98 场强归一化，颜色不适合直接跨场景比较绝对场强，应以数值采样为准。

静电场是二维教学近似，采用边界离散化，并沿用空腔内表面清零、腔内电荷场景外表面平均化等显示修正。净电荷约束可达到数值精度，但不意味着每个局部场值具有相同精度。例如默认腔内单位正电荷的离散内表面总电荷约为 -1.060，偏离理想值 -1 约 6%。诊断读数保留此误差，不将其当成三维精确解。避免用此模型作定量测量或高精度求解。

`tests/fields.test.js` 检查模型约束、实例隔离、计算输出与线程取消；`tests/browser/fields.spec.js` 检查桌面和手机上的场景切换、预测、拖动、暂停、重置、退出清理与本地依赖。
