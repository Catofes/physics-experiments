# 物理实验室 v0.1.1

本版本清理 Docker 镜像的端口声明，容器列表仅显示网站实际使用的 `8080/tcp`。

- 源码镜像与静态交付包均以 `scratch` 为起点，复制官方 Caddy 镜像的运行文件，保留 Alpine 工具、Caddy 启动环境及健康检查。
- 不再继承 `80/tcp`、`443/tcp`、`443/udp` 和 `2019/tcp` 声明。
- CI 检查两种构建方式均仅声明 `8080/tcp`。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.1.1`，拉取后重新创建容器；仅重启旧容器不会更新端口列表。现有端口映射可以保持，例如 `127.0.0.1:18082:8080`。

网站功能和访问方式不变。通过 `/version.json` 确认版本及来源提交。
