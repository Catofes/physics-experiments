# 物理实验室 v0.3.0

本版本新增示波管高频演示，可对比低频光点运动、高频亮线和同步扫描波形。

- 示波管信号与扫描频率扩展至 0.1–1000 Hz，使用对数滑块按倍数调节。
- 新增低频光点、高频成线和高频扫描波形三种演示预设，切换后自动进入正面观察。
- 荧光屏增加帧间轨迹采样及余晖衰减，避免高频信号因刷新率采样而呈现静止光点；回扫、消隐和方波跳变保持轨迹断开。
- 高频电压图使用毫秒窗口展示波形，低频保留每秒 60 CSS 像素的时间轴。
- 补充不同刷新率下的高频轨迹覆盖、消隐与方波断开及毫秒窗口回归检查。

荧光屏轨迹和余晖为教学用视觉近似；管内电子束表示当前时刻的偏转。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.3.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布不会自动部署到教学服务器。
