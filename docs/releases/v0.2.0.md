# 物理实验室 v0.2.0

新增磁场和静电场两个站内实验，目录现有四个实验，共用导航、全屏、暂停、重置和手机布局。

- **磁场可视化实验室**：地磁场、条形磁铁、弯折导线、通电直导线、双导线、环形电流、通电螺线管；支持场源参数、预测模式、截面投影、热力图、点选场强和双导线矢量合成。
- **静电场可视化实验室**：默认腔内电荷，另有带电球体、空腔屏蔽、尖端效应、哑铃导体、避雷针、实心导体；支持电荷拖动、正负与大小、预测模式、场线、等势线和诊断。
- Three.js 和磁场后台计算线程随静态资源打包，退出实验时释放动画、事件、线程和图形资源。
- 新增目录封面、数值关系与任务取消测试，补充桌面／手机交互、直接访问、刷新和资源清理检查。

两个实验沿用 jaccihan 提供的参考模型，详见交付包中的 `docs/SOURCES.md`。静电场为二维教学近似，默认腔内单位电荷的离散内表面总电荷偏差约 6%，适合定性演示；磁场热力图按当前截面归一化，定量比较请使用场强读数。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.2.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本及来源提交。发布不会自动部署到教学服务器。
