# 物理实验室 v0.2.1

本版本修正静电场和示波管实验中的显示与默认参数。

- 腔内电荷总量不变时，移动电荷不再改变腔外等势线；保留腔内场与内表面电荷分布的变化。
- 示波管电压图横轴固定为每秒 60 CSS 像素，并显示秒刻度。宽屏显示更多历史，波形宽度和滚动速度保持一致。
- 电压控件使用“直流偏置”文案。
- 回扫消隐占比默认设为 0%，重置后同样恢复为 0%；电压图显示理想锯齿波的垂直下降沿，仍可手动调节非零回扫时间。

补充腔外电势、电场与像素稳定性检查，以及时间轴比例、历史保留、锯齿波交界和重置行为的回归测试。静电场仍为二维教学近似，详见模型来源说明。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.2.1`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布不会自动部署到教学服务器。
