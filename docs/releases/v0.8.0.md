# 物理实验室 v0.8.0

本版本新增游标卡尺和螺旋测微器两个测量实验，让学生对照仪器操作、刻度对齐和读数步骤学习长度测量。目录新增「测量」分类，共十七项实验。

- 游标卡尺支持 10、20、50 分度及自动对齐演示，采用课本短游标结构，分别以 9、19、49 mm 分成 10、20、50 格，分度值为 0.1、0.05、0.02 mm。主尺数字只标 0、10、20 等整十毫米，提供刻度放大、轻合量爪和隐藏答案练习。
- 螺旋测微器以 0.5 mm 螺距联动测微螺杆和可动刻度，放大固定刻度、半毫米线及圆周刻度，提供进位边界和估读预设。每格 0.01 mm，读数记录到 0.001 mm，最后一位为估读。
- 两个仪器均提供共用测量状态的示意图与三维模型，支持旋转、缩放、直接拖动、正面读数和测量面近景；部件名称与字母标注对应课本。
- 对照实物及三维参考模型调整卡口、刀口、压板与导槽；内测爪前后错层，下部压板前缘与活动量爪齐平，刻度斜面贴近主尺。正面读数采用正投影，减少厚度造成的透视错位。测微器修正固定刻度零点、尺架和金属滚花旋钮。
- 增加读数与几何回归，验证桌面和手机的操作、三维状态联动及退出清理，并检查闭合、小开口等状态下的网格避让。

测量模型无零误差，不模拟测力、形变或校准误差；三维视图需要 WebGL，加载失败时可继续使用示意图。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.8.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布流程不会自动更新服务器。
