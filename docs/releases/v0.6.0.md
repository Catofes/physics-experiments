# 物理实验室 v0.6.0

本版本新增八个站内实验，覆盖航天轨道、滑动变阻器及电表改装，并改进公共参数输入与演示交互。

- 新增六个航天与轨道实验：牛顿大炮、卫星变轨实操、地月卫星变轨、同步卫星星下点轨迹、地月绕日轨迹和嫦娥六号地心轨迹，实验目录扩展至十四项。
- 变轨实验支持暂停后精调速度、轨道前后对照、事件合并及档案导出、读取和回放；星下点实验提供三维地球、轨道参考面及卫星跟随视角。
- 新增「滑动变阻器：分压与限流」，联动展示三维接线装置、电路图、仪表与负载电压曲线。
- 新增「电表改装」，分步演示电流表、电压表、欧姆表的计算、接线、刻度和验证，并支持双量程扩程与欧姆表倍率调零。
- 统一滑块支持键盘精确输入及数字按键板；优化电阻 24 点操作布局、实验分类和磁感线方向箭头的分布与缩放。
- 补充模型边界、素材来源、物理关系与桌面／手机交互回归，提供 make dev 开发入口。

航天实验采用教学近似；“嫦娥六号地心轨迹”是理想化环月模型，不是实际任务轨迹。地月变轨中的暂时束缚不代表长期捕获。详细边界见 [航天实验来源与模型说明](https://github.com/Catofes/physics-experiments/blob/v0.6.0/docs/ORBIT-SOURCES.md)。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.6.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布不会自动部署到教学服务器。
