# 物理实验室 v0.9.0

新增「测量电源电动势和内阻」课堂演示实验，目录共十八项。入口为 `/experiments/emf-internal-resistance`。

- 限流接法电路图联动滑片、电表示数和描点；支持手动记录或一键采集六组，拟合电动势与内阻，并查看原始数据。
- 图像固定横轴电流 I、纵轴电压 U，显示完整两轴截距，说明纵截距、横截距和斜率的物理意义。电路始终接通，直接用于原理讲解。
- 比较理想电表和同时具有内阻的非理想电表。电流表相对被测电源的外接突出电压表分流，内接突出电流表分压；图像标出测量点到真实点的偏移，用已知电表内阻逐点修正后重新拟合。
- 电源内阻可调 0.2～5000 Ω，水果电池情境采用 E = 1.0 V、r = 500 Ω 的示例值；负载范围和采样点自动匹配。读数、数据表和电流坐标统一切换 A / mA / μA，并说明图像斜率换算为 Ω 的倍率。
- 增加物理关系和桌面、手机交互回归。发布流程复用交付包，并行检查两种屏幕；默认排除较重的三维浏览器用例，可手动启用 full_e2e 完整检查。
- 间接构建依赖 source-map-js 更新到 1.2.2，修复索引 source map 偏移量校验问题。

模型采用固定电动势与固定内阻的线性近似，集中演示电表内阻造成的系统误差；不模拟水果电池极化、内阻随时间变化、随机读数误差或电表量程过载。水果电池示例值不代表所有实际装置。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.9.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。
