# 物理实验室 v0.10.0

实验目录新增「振动与波」分类，共收录二十个站内实验。

- 「机械振动和机械波」入口为 `/experiments/mechanical-waves`。七项演示涵盖弹簧振子、单摆、简谐振动、阻尼振动、横波、纵波和波的叠加。支持调参、暂停、重置和逐帧观察。
- 「机械波干涉」入口为 `/experiments/wave-interference`。可切换一维叠加与二维水波，对比稳定干涉、频率不同、不等振幅与反相波源。可拖动观察点或沿加强和减弱曲线选点，并对照波的到达时间、路程差与合振动图像。
- 两个实验共用站内返回导航和全屏操作。桌面与手机测试覆盖目录发现、演示切换、干涉预设和直接刷新。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.10.0`，也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。
