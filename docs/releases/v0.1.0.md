# 物理实验室 v0.1.0

首个版本提供面向高中物理课堂的统一交互实验网站。

- 目录支持分类、知识点搜索与响应式布局。
- 收录深蹲跳和示波管原理两个实验，统一导航、参数、暂停、重置与全屏。
- 计算与绘图拆成模块，退出时清理动画和三维资源。
- 演示无需外部 CDN；示波管需要浏览器支持 WebGL 2。
- 提供静态交付包、SHA-256 校验、amd64/arm64 Docker 镜像及交接文档。

默认端口 `8080`。使用镜像 `ghcr.io/catofes/physics-experiments:0.1.0`，或下载本页交付包校验后自行封装。通过 `/version.json` 确认版本与来源提交。

实验采用教学示意参数；课堂使用前应在实际投影设备上检查显示与交互效果。
