# 物理实验室 v0.5.0

本版本新增「电阻 24 点」小游戏，通过搭建串并联电路练习等效电阻计算。

- 新增「电阻 24 点」小游戏，使用 3～4 个电阻串并联，使等效电阻恰好为 24 Ω。
- 提供入门、进阶、挑战各 4 题；所有题目均需串并联混合，挑战题必须使用嵌套连接，题库通过穷举验证。
- 实时展示完整电路图与精确分数计算，支持撤销、重来、切题、分步提示、参考解和本次独立完成进度。
- 适配桌面和手机，复用站内导航与全屏布局；补充物理计算、题库及浏览器交互回归。

入口为 `/experiments/resistance-24`，也可从首页实验目录进入。每个电阻必须使用一次；查看过提示或参考解的题目不计入独立完成，进度仅保留在当前页面会话。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.5.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布不会自动部署到教学服务器。
