# 物理实验室 v0.4.0

本版本新增「李萨如图形」实验，通过两个垂直方向的正弦电压观察简谐运动合成。

- 支持独立调节 X、Y 电压的幅值、频率和初相。
- 提供直线、圆、椭圆、8 字形、2:3 多瓣曲线及高频成线预设；圆形按两方向偏转灵敏度校正幅值。
- 正弦 X 电压跨周期连续且不触发回扫消隐，原示波管继续使用锯齿扫描。
- 实验目录扩展至五项，补充物理关系和桌面、手机交互检查，并修正目录数量回归断言。

荧光屏轨迹和余晖为教学用视觉近似；管内电子束表示当前时刻的偏转。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.4.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布不会自动部署到教学服务器。
