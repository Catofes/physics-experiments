# 物理实验室 v0.7.0

本版本新增竖直圆周运动教学实验，帮助学生理解分离条件、受力变化与后续抛体运动。

- 新增力学实验「竖直圆周运动与分离」，目录扩展至十五项，比较低速折返、途中分离、临界过顶与完整绕行。
- 支持慢放、时间回看及分离瞬间自动暂停，展示分离后的重力抛体轨迹，再次接触轨道时停止。
- 初速度直接使用 m/s 调节，预设标明根式；符号与公式统一采用 LaTeX 排版，改进矢量箭头。
- 使用全程固定刻度对照所需向心力、重力径向分量与支持力，明确分离时支持力为零、重力仍然存在。
- 地磁场地球模型增加本地地表贴图，并调整透明度以保留球内与背面的磁感线。
- 补充能量守恒、临界条件、分离角、抛体轨迹与箭头比例回归，验证桌面和手机操作。

模型采用光滑圆轨道内侧的质点，分离前考虑重力与支持力，分离后只受重力，忽略摩擦和空气阻力，不模拟再次接触后的碰撞。最高点临界速度为 √(gr)，对应最低点初速度 √(5gr)；初速度很低时会沿圆弧折返，并非一定分离。

升级镜像为 `ghcr.io/catofes/physics-experiments:0.7.0`，拉取后重新创建容器；也可使用本 Release 的静态交付包。通过 `/version.json` 确认版本与来源提交。发布不会自动部署到教学服务器。
